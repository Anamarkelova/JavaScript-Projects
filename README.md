# JavaScript-Projects

Welcome to my JavaScript Projects repository!

This repository contains the coding projects, assignments, and challenges I completed throughout The Tech Academy JavaScript course.

As I progressed through the course, I practiced JavaScript programming concepts and used HTML, CSS, and JavaScript to create interactive webpages and applications.

## Projects

### Basic JavaScript Projects

These projects introduced fundamental JavaScript concepts and helped me practice writing and executing JavaScript code.

Topics included:

- Expressions and alerts
- Functions
- Mathematical operations
- Dictionaries and objects
- Comparisons and type coercion
- Ternary operators
- Constructor functions
- Scope and debugging
- Time functions
- String methods

### Countdown Slideshow

This project uses HTML, CSS, and JavaScript to create an interactive slideshow. It includes multiple images, slideshow navigation, and a countdown function.

### Loops and Arrays

This project demonstrates JavaScript loops, arrays, constants, objects, object methods, break statements, and continue statements.

### Pizza Menu

The Pizza Menu project is an interactive ordering application. Users can select a pizza size and toppings, and JavaScript calculates the total price and displays an order receipt.

### Tic-Tac-Toe Game

This project is an interactive Tic-Tac-Toe game created with HTML, CSS, and JavaScript.

The game includes:

- X and O players
- Winning combinations
- Computer moves
- Sound effects
- Winning-line graphics
- Interactive game squares

### Calculator

This project is a basic web calculator created with HTML, CSS, and JavaScript.

The calculator allows users to perform common mathematical operations, including:

- Addition
- Subtraction
- Multiplication
- Division

### AJAX Projects

These projects introduced AJAX and demonstrated how JavaScript can be used to retrieve and display information without requiring an entire webpage to reload.

### jQuery Projects

These projects introduced the jQuery JavaScript library. I practiced using jQuery to select HTML elements, respond to events, and create webpage effects.

### Bootstrap Projects

These projects introduced Bootstrap and demonstrated how to use a framework to create responsive webpage layouts and styled components.

### React Project

This project introduced React and demonstrated the use of React components and JavaScript to create webpage content.

### Portfolio Website

My portfolio website combines HTML, CSS, and JavaScript to create a personal portfolio.

The website includes:

- Home section
- About Me section
- GitHub link
- LinkedIn link
- Images
- Contact form
- JavaScript form validation
- Interactive webpage elements
